# Agent instructions

This repo teaches original Discord server and pack design.

When the user asks for a Discord server, بكج, welcome, info, line, store, event, or listing card:

1. Read `.cursor/skills/discord-server-design/SKILL.md` (identity, banners, marketplace cards).
2. Read `.cursor/skills/discord-pack-design/SKILL.md` (matching kit: icon, welcome, info, lines, headers).
3. Plan color / type / motif tokens before drawing.
4. Export original PNG/GIF. Do not copy existing server brands.

Prompt examples the agent should treat as this skill:

- "Make a full Discord pack for a luxury Arabic shop server named Qamar"
- "Server icon + banner only"
- "Welcome banner with avatar hole, gold and black"
- "Listing card 1920x1080, Arabic pills"

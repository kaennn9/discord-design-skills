# Marketplace and listing cards

Study folders: `discord-design/servers` (61), `stores` (12), `events` (18). All 1920×1080 PNG.

These are **catalog UIs** wrapping a server identity. Use them when the user wants a storefront shot, a portfolio, or a listing.

## Dark metal catalog

- Background: near black, faint marble cracks, top spotlight, small mark top-center
- Left rail: icon+label rows (Servers, Stores, Avatars, Events)
- Top stadium: circular icon + display name
- Main device: rounded “screen” with the 16:9 banner
- Three dots on the device bezel (pack chrome leaking into UI)

Use for luxury, shops, serious communities.

## Light lavender catalog

- Background: pale periwinkle blobs
- Top pills, Arabic, active pill filled
- Stacked rounded screens (depth via offset cards)
- Banner on the main card, circular icon overlapping the right
- Tiny wordmark + `Server`

Use for modern, soft, consumer listings.

## Store listings

Hero is a **brand**, often with phone mocks, grids, or logo on a dark grid. Name includes Store. Sidebar `Stores` state selected.

## Event / profile listings

Editorial collage: Arabic display type (`افضل بروفايل`), 2–3 phone/profile shots, stacked cards, decorative letterforms. Not a server icon crop.

## Rules for original listing art

- 1920×1080
- Show the real icon and banner you designed, not a screenshot of Discord’s UI (ugly font scaling)
- One product per card
- Keep the catalog chrome consistent if making a series
- Arabic type: display size, not body; never fake-bold
- Do not copy competitor names or marks from the study folder

# Examples (original recipes, not copies)

Use these as starting briefs. Invent new marks.

## 1. Quiet Ramadan shop

- Colors: `#070B14` void, `#1B2A4A` mosque, `#5B7CFF` lantern, `#F4F6FF` highlight
- Motif: hanging lanterns in corners only; faint dome silhouette; no calligraphy stolen from known packs
- Icon: lantern monogram, circle
- Banner: 1920×1080, lanterns top corners, empty center
- Info: 1800×600 rounded, 3 dots, lanterns right edge
- Line: 1400×72, tiny lanterns at ends
- Welcome: left circle rim `#5B7CFF`, navy ribbon, word `أهلاً`

## 2. Liquid metal server

- Colors: `#0A0A0C`, `#6E6E78` steel, `#C8CDD8` highlight, `#5B3D9C` wash (sheet only)
- Motif: chrome silk folds, engraved edge pattern
- Banner: name in white sans, subtitle `Server`
- Welcome: black hole + steel ribbon, no extra background
- Round icons: music / game / settings cut from the same metal

## 3. Gold fracture

- Colors: `#161616`, `#C9A227` gold, `#F8E38A` strike, `#2A2A2A` mid
- Motif: torn gold shards on corners of info **and** the line (the line is a crop of the info edges)
- Info center stays charcoal so overlay text reads

## 4. Geometric classic

- Colors: muted violet ribbons `#9A8FB0` on pale grey field `#D9D9DE`
- Motif: folded corner bands, faint diamond lattice in the quiet field
- Works for “Discord Classic” wide 1500×500 info plates
- Icon: abstract teal or violet ribbon knot, 512, no text

## Filename map from study library (roles only)

When grouping a client pack, name by role not by Discord message id:

- `banner`, `logo`/`icon`, `welcome`/`wlc`, `info`, `line`
- `ticket`, `giveaway`, `music`, `system`/`bot`, `prove`/`verify`

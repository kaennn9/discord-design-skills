# events

18 listing cards, 1920×1080. Catalog chrome with **Events** selected (or Arabic `فعاليات`).

## What they are

Editorial product cards for events / “best profile” packs, not server icons.

- Dark metal: left rail Events, big Arabic headline (`افضل بروفايل`), 2–3 profile mocks on a grey device
- Light lavender: pill `فعاليات`, stacked cards, Arabic display type + English sub (`Best Profile`), profile screenshots as collage

Denser than server listings. Type is a headline, not a tiny subtitle.

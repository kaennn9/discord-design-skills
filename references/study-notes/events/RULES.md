# events — design rules

1. 1920×1080 editorial card, not a cropped server banner.
2. One headline (often Arabic) + optional English sub.
3. Two or three UI mocks max. More becomes noise.
4. Keep a clear active nav state (Events / فعاليات).
5. Do not steal profile screenshots from this folder; mock with original or licensed avatars.
6. Date/time for real Discord scheduled events belongs on a **1600×640** event cover, separate from this catalog card.

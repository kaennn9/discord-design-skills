# Discord Classic — design rules

1. Restraint is the style. One motif (smoke or folded ribbon), muted palette.
2. Info plates: 1500×500 or 1800×600, no large type, center quiet.
3. Corner ribbons / lattice stay in the margin.
4. Logos: abstract, circular, 512, no letters unless the brief is a monogram.
5. Do not add 3D glossy Discord logos or purple blurple unless asked — this folder is not “Discord brand”, it is a quiet classic pack language.
6. Pair info + pack pieces with the same grey/violet or teal family.
7. Original folds and smoke; do not trace these files.

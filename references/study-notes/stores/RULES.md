# stores — design rules

1. Name pattern: `{Mark} Store`.
2. Lettermark or abstract logo, 512 circle, high contrast.
3. Banner: logo + grid / light streak / product, not a crowd or anime cast.
4. Listing: Stores rail selected; same chrome family as the server catalog if they are one marketplace.
5. Inner pack headers may include shop, ticket, laws (`القوانين`, `البوستات`).
6. Original marks only. Do not rebuild Nuit or other logos here.

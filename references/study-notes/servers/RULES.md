# servers — design rules

1. Identity first: 512 icon + 1920×1080 banner that share DNA.
2. Listing card is optional packaging at 1920×1080.
3. Pick one catalog skin (dark metal or light lavender) and keep it for a series.
4. Show icon + banner together. Never four random screenshots.
5. Wordmark: one name + tiny `Server`.
6. Arabic nav labels only if the catalog is Arabic.
7. Do not copy listed server names or art (Ashn, Lust, and others in this folder).
8. Icon must be a distilled mark of the banner, not a squeezed banner.

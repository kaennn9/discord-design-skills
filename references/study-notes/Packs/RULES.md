# Packs — design rules

1. Lock tokens before any asset: 4–6 hex, 1 motif family, 1 light direction, 1 type pair.
2. Export the bill of materials: icon 512, banner 1920×1080, welcome transparent, info ~3:1, line ~16:1, headers, round function icons.
3. Welcome: left circle hole + rim, no light rectangular background.
4. Info: ornament the edges, leave the middle 50% empty.
5. Line: 50–120px tall. Same motif as info corners.
6. Round icons: one glyph, same texture as the banner, circle-safe.
7. Name files by role (`{slug}-welcome.png`), not by Discord message ids.
8. Original marks only. Do not rebuild LadyR or pixelcut compositions from this folder.
9. Ship a 1920×1080 sheet if the pack is for a client (see Packs-paulk).
10. Matching test: all pieces on `#1e1f22` must look like one family in two seconds.

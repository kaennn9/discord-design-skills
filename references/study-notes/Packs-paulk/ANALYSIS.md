# Packs-paulk

14 PNG presentation sheets (not in-channel assets). This is how a professional Discord designer **delivers a pack to a client or store**.

## What the images are

Single 16:9 (or near) artboards that show the whole kit:

- Hero banner with wordmark (`ALPHA`, `NRS`, `Sorn`)
- Circular server icon
- Channel headers (`البوستات`, `القوانين`, `NEWS`)
- Round function icons (gears, ticket, cart, share, music, game)
- Optional iPhone invite mock
- Studio credit + `discord.gg/...`

Sizes cluster around 1115×627, 736×414, 1200×675 — marketplace/thumbnail friendly, plus a few 16:9.

## Visual languages sampled

- Dark red HUD / pixel display type (NRS)
- Chrome silk + violet wash (Sorn / Roiz Store)
- Red device mock + Arabic product copy (ALPHA)

The sheet background is a wash of the identity color, not Discord’s UI.
